Fuel Fasta

Fuel Fasta is a mobile application designed to help Bolt drivers access fuel discounts when refueling at partner gas stations.

Features

- Scan QR code from fuel receipt
- Record fuel transactions
- Track fuel usage and spending
- Simple and user-friendly interface

Tech Stack

- React Native
- JavaScript
- API Integration

How It Works

1. Driver refuels at a Fuel Fasta partner station
2. Opens the app
3. Scans QR code from receipt
4. Transaction is recorded and discount applied

Fuel Fasta

Fuel Fasta is a mobile application designed to help Bolt drivers access fuel discounts when refueling at partner gas stations.

---

Features
- Scan QR codes from fuel receipts  
- Record fuel transactions  
- Track fuel usage and spending  
- Simple and user-friendly interface  

---

Tech Stack
- React Native  
- JavaScript  
- API Integration  

---

How It Works
1. Driver refuels at a Fuel Fasta partner station  
2. Opens the app  
3. Scans QR code from the receipt  
4. Transaction is recorded and discount is applied

Problem It Solves
- Many drivers face challenges in tracking fuel expenses and accessing consistent discounts. Fuel Fasta addresses this by digitizing fuel transactions and enabling drivers to benefit from structured discount systems, improving cost efficiency and operational sustainability.
